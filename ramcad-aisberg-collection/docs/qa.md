# Проверка комплекта

Дата: 29 октября 2026.

## Выполнено

- Сверены восемь этикеток: название, формат рыбы, масса и изображённые добавки.
- Проверены восемь PNG-макетов 1774 × 887 и общий обзор. Рыба и этикетка сопоставлены для каждого товара; композиции проверены на обрезание и перекрытие интерфейса.
- Проверены 10 HTML-страниц: каталог, конструктор, восемь карточек. На каждой один h1, нет повторяющихся ID, у изображений есть alt.
- Проверены 380 локальных ссылок в HTML, CSS и SVG. Все зависимости на месте. `/about/` и `/contacts/` — намеренно оставленные маршруты сайта для интеграции.
- Проверены 35 SVG-документов на корректность XML.
- Проверены синтаксис JavaScript, восемь пар fish/label, соответствие масс и форматов, синхронность `products.json`, `scripts/products.js` и отдельных JSON товаров.
- Все восемь включённых PDF побайтно совпадают с присланными исходниками.
- Шесть рабочих PNG рыбы имеют альфа-канал с прозрачными и непрозрачными областями. Оба шрифта содержат нужную кириллицу.
- Оценена ширина длинного десктопного подзаголовка по метрикам Prata при 981, 1024, 1279, 1280, 1440, 1774 и 1920 px: он помещается в расчётную ширину панели.

Повторить статические проверки: `python3 tools/check.py`.

## Границы проверки

Полноценный запуск HTML в браузере и интерактивная проверка в этой среде не выполнены. PNG — рендеры нативных векторных макетов, не скриншоты HTML. Проверка ссылок, синтаксиса и геометрии не заменяет браузерную проверку.

После интеграции проверить страницы при 390, 768, 1024, 1440 и 1774 px: реальную загрузку шрифтов, отсутствие горизонтальной прокрутки, видимость всей группы товара на мобильном, меню, три режима галереи, аккордеоны, диалог и фокус клавиатуры. В конструкторе проверить выбор всех товаров, ползунки, сброс, скрытие слоёв, копирование и скачивание HTML.

Физическая упаковка для разных масс остаётся концептуальной моделью; для финальной товарной съёмки нужны фотографии соответствующей тары. Контакт из референса и служебные маршруты должны быть подтверждены при подключении сайта.
