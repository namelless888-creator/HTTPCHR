# Происхождение и использование ресурсов

## Рыба

| Файл | Подготовка |
|---|---|
| `assets/fish/oil-180.png` | Изображение извлечено из PDF 180 г в масле с исходной прозрачностью |
| `assets/fish/oil-500.png` | Восстановление детализации изображения из PDF 500 г; композиция и лук сохранены |
| `assets/fish/spices.png` | Изображение из двух этикеток с пряностями, исходники одинаковые |
| `assets/fish/ruby.png` | Изображение из PDF «Рубиновая» |
| `assets/fish/steaks.png` | По изображению 725 г: удалена тарелка, сохранены шесть кусков и специи |
| `assets/fish/fillets.png` | По изображению 900/2000 г: удалена тарелка и внешняя сервировка, сохранены три длинных филе |

Файлы `source/oil-500-original.png`, `source/steaks-on-plate.png`, `source/fillets-on-plate.png` сохраняют исходный визуальный материал до подготовки. Все исходные PDF включены в папки товаров. Рыба не перекрашивалась под акценты интерфейса.

Восстановление разрешения и удаление тарелок выполнены генерацией по конкретным исходным изображениям. Это подготовленные рекламные вырезки, не дополнительные фотографии реального продукта. У вариантов с методом `original-pdf-image` сохранено извлечённое изображение; CMYK переведён в RGB при извлечении, где это требовалось форматом PDF.

## Этикетки

`products/<id>/label.png` — рендер оригинального PDF на белой подложке, необходимой для корректного отображения прозрачных элементов PDF. Полный исходник — `source-label.pdf`. На макете этикетка накладывается отдельным слоем в овал крышки. Название, масса и рисунок этикетки не набирались заново.

Текст мелкой маркировки предназначен для просмотра в исходном PDF. На уменьшенном веб-макете он не обязан читаться как печатный оригинал.

## Фон и упаковка

`assets/studio/ice-background.png` — студия с колотым льдом без товара и интерфейса, подготовлена по прежнему стилю. `assets/packaging/tub-blank.png` — прозрачный контейнер с пустой крышкой для точной этикетки. Контейнер общий, его масштаб в композициях условный. Физическая тара, содержимое за прозрачными стенками и пропорции вместимости не подтверждены фотографиями для каждой массы.

В основной композиции рыба рядом с упаковкой соответствует этикетке. При появлении настоящих packshot-фотографий заменяйте модель контейнера соответствующим реальным товаром. Не меняйте привязку рыбы к этикетке.

## Паттерны, шрифты, иконки

Паттерны волн и студийного градиента, линейные иконки 24 × 24 — отдельные SVG. Надпись RAMCAD доступна как SVG и как текст в Prata. Это набор, подготовленный по референсу, не предоставленный официальный брендбук.

Prata Regular и Manrope Variable содержат кириллицу. Они приложены вместе с лицензиями SIL Open Font License в `assets/fonts/`. В HTML шрифты подключены локально.

## Векторные композиции и PNG

`layout.svg`, `photo-layers.svg`, `packshot.svg` хранят исходные изображения по относительным путям. Сохраняйте папку целиком. Встраивание такого файла через `<img>` может блокировать вложенные ссылки: используйте HTML-композицию, inline SVG или готовый `mockup.png`. Слой текста макета находится в контурах для одинаковой типографики при рендере; текст на веб-странице обычный HTML.

`tools/render.cjs` временно встраивает связанные изображения в SVG перед растеризацией. Он формирует PNG-эталоны; HTML-браузер этот скрипт не запускает. `previews/collection-overview.png` — лист из восьми таких эталонов.

## Пересборка

Для просмотра комплекта ничего устанавливать не нужно. Только для повторной генерации нужны Python с `fontTools` и Node.js с `sharp`:

```sh
python3 tools/build.py
python3 tools/overview.py
node tools/render.cjs
```

`build.py` использует собственный `tools/product-template.html`. Редактируйте шаблон для изменений, общих всем страницам; `products.json` — для данных и координат. `scripts/products.js` и отдельные `product.json` синхронизируются при сборке.
