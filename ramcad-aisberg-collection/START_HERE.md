# RAMCAD × Айсберг — восемь карточек товара

Откройте `index.html`: это каталог всех восьми макетов. Каждый товар имеет отдельную HTML-страницу и PNG-макет 1774 × 887. Откройте `constructor.html`, чтобы переключать товары, двигать рыбу и упаковку, менять размеры и экспортировать текущую композицию.

## Передача Claude

Передайте всю распакованную папку и текст `CLAUDE_PROMPT.md`. Относительные пути внутри папки необходимо сохранить. Отдельный PNG служит визуальным ориентиром; интерфейс собирается из готовых HTML-компонентов и CSS.

## Что внутри

| Путь | Назначение |
|---|---|
| `index.html` | Каталог восьми страниц |
| `constructor.html` | Общий конструктор слоёв с выбором товара |
| `products.json` | Данные, соответствия изображений и координаты всех товаров |
| `products/<id>/index.html` | Готовая адаптивная страница конкретного товара |
| `products/<id>/mockup.png` | Визуальный макет 1774 × 887 |
| `products/<id>/layout.svg` | Векторный макет с редактируемыми слоями |
| `products/<id>/photo-layers.svg` | Только фотокомпозиция: лёд, контейнер, этикетка, рыба |
| `products/<id>/packshot.svg` | Сборка контейнера и точной этикетки |
| `products/<id>/label.png` | Рендер оригинальной этикетки |
| `products/<id>/source-label.pdf` | Ваш исходный PDF без изменения |
| `products/<id>/product.json` | Данные одного товара |
| `assets/` | Рыба, лёд, контейнер, паттерны, иконки, шрифты |
| `styles/` и `scripts/` | Общие стили и поведение интерфейса |
| `previews/collection-overview.png` | Обзор всех восьми макетов |
| `docs/` | Спецификация, компоненты, происхождение ресурсов и проверки |

## Как устроена рыба

Для 180 г в масле, 180/500 г с пряностями и 500 г «Рубиновая» использованы изображения, извлечённые из самих этикеток. Для 500 г в масле подготовлена более чёткая версия исходного изображения 410 × 410; оригинал также включён. Для 725 г и филе 900/2000 г рыба подготовлена по соответствующим изображениям: убрана тарелка, сохранён вид нарезки. Подробное соответствие — в `docs/product-mapping.md`.

## Что можно менять

- Текст и изображения: `products.json`, затем пересборка, либо непосредственно HTML нужной страницы.
- Цвета и шрифты: `styles/tokens.css`; оттенок конкретного варианта — `accentTint`.
- Положение рыбы и упаковки: конструктор или `fishBox` / `packBox` в данных.
- Телефон и маршруты: `scripts/site-config.js`.

Конструктор экспортирует сцену в HTML с CSS. Сохраните скачанный файл в корень этой папки: ему нужны соседние `assets` и `products`. Настройки конструктора не перезаписывают исходные страницы автоматически.

## Просмотр и интеграция

Для простого просмотра не нужны npm, сборка или интернет: откройте HTML-файлы. Если браузер ограничивает локальные шрифты или буфер обмена, запустите локальный HTTP-сервер в этой папке. Копирование кода имеет ручной запасной вариант и отдельную кнопку скачивания HTML.

`layout.svg`, `photo-layers.svg`, `packshot.svg` используют относительные ссылки на соседние изображения. Открывайте их в редакторе с поддержкой связанных ресурсов или встраивайте SVG-разметку в документ. Для обычного `<img>` используйте `mockup.png`; сборка товара в HTML уже сделана отдельными `<img>`-слоями.

Форма и размер контейнера — визуальная модель. Фотографии настоящей тары для каждой массы не предоставлялись. Телефон перенесён из исходного референса; перед интеграцией проверьте его и замените служебные маршруты `/about/`, `/contacts/`.

PNG-макеты проверены визуально; браузерная проверка готовой интеграции остаётся обязательной. Подробнее — `docs/qa.md`.
