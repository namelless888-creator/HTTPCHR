# RAMCAD — многостраничный макет

- `index.html` — Главная
- `catalog.html` — Каталог: поиск, фильтры, карточки 36 товаров
- `about.html` — О компании и сотрудничество
- `news.html` — Новости: архив публикаций
- `contacts.html` — Контакты и маршрут

Общие файлы: `styles.css`, `app.js`. Фотографии используются из `../public/images/catalog/`. Сохраняйте структуру репозитория при переносе.

Это статический макет; отдельный HTML-файл больше не содержит все страницы и изображения. Для просмотра скачайте репозиторий целиком или разместите его на статическом хостинге. Живой домен icechr.ru этими файлами не изменяется.
