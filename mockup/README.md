# RAMCAD — многостраничный макет

Пять страниц: index.html, catalog.html, about.html, news.html, contacts.html.

Оформление, JavaScript и используемые фотографии встроены в каждый HTML-файл. Внешние CSS, JS, интернет и папка фотографий для отображения не нужны. Для переходов между страницами все пять HTML-файлов должны находиться в одной папке.

Скачайте ZIP репозитория через Code → Download ZIP, распакуйте и откройте mockup/index.html. Не переносите только один файл, если нужны переходы между страницами.

styles.css и app.js сохранены как редактируемые исходники; HTML использует встроенные копии. Живой сайт icechr.ru не изменён. Контакты и архивные новости требуют редакционной проверки перед запуском.
