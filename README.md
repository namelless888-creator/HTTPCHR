# RAMCAD — одностраничный сайт

Сайт хладокомбината на Next.js 16, React 19 и TypeScript. Визуальное направление основано на макетах и аннотациях из соседнего репозитория `ramcad-assets`: крупная продукция MARZO, холодная палитра, верхняя навигация и видео-карта на фоне контактов. Первые два блока повторяют предоставленные макеты: светлый первый экран и тёмный блок с двумя фотографическими карточками.

## Разработка

Проверено с Node.js 24.19.0 и npm 11.9.0.

```bash
npm ci
npm run dev
```

Производственная сборка и запуск:

```bash
npm run build
npm run start
```

Шрифты Manrope и Playfair Display хранятся локально в `public/fonts` вместе с лицензиями SIL OFL. Для сборки и просмотра не требуется Google Fonts. Дополнительные переменные окружения, ключи и база данных не нужны.

## Что работает

На главной странице собраны направления продукции, каталог, блок «О компании», архив новостей и контакты. Навигация ведёт к секциям этой страницы; прежние адреса `/catalog`, `/news` и `/contacts` перенаправляют к соответствующим якорям.

Каталог содержит 36 товаров, шесть фильтров, разворачивание полной коллекции и подробные карточки. Диалог поддерживает клавиатуру, Escape и возврат фокуса. Кнопки сотрудничества открывают почтовую программу, телефон — звонок. Форма с имитацией успешной отправки на новой странице не используется; существующий `/api/contact` остаётся заглушкой и не отправляет сообщения.

При прокрутке появляются блоки, меняется активная секция навигации и заполняется индикатор чтения. Карточки направлений слегка увеличивают фотографию при наведении. В контактах маршрут показан фоном: в полной версии и предпросмотре это предоставленное видео. Отдельного вводного блока перед картой нет. Адрес, телефон, почта и часы работы размещены в карточке «Контакты» поверх анимированной карты; внешней карты и переключателей нет. Кадр анимации напрямую связан с прокруткой: карта прорисовывается до конца ближе к завершению блока. Завершение ограничено доступной прокруткой страницы, чтобы финальный кадр был доступен и на телефоне. Прокрутка вверх обращает анимацию; кадры плавно догоняют позицию прокрутки со сглаживанием 220 мс. Видео подготовлено с ключевыми кадрами через 200 мс для быстрой перемотки. Автоматического воспроизведения нет. При `prefers-reduced-motion` параллакс, плавная прокрутка и анимации отключены, видео приостановлено.

## HTML-версия

`ramcad.html` в корне репозитория — полностью автономный HTML: изображения, видео, CSS и шрифты встроены в один файл (около 30 МБ). Его можно перенести отдельно от остальных файлов.

`preview.html` — автономный предпросмотр со встроенной анимацией карты. Изображения сохраняют исходные размеры и экспортируются в WebP с качеством 95, без уменьшения до миниатюр. Для первого экрана и фотографий в основной версии используются исходные PNG без дополнительного сжатия. Видео маршрута встроено в предпросмотр в разрешении 1920×1080; подключения к картографическим сервисам нет. Работу встроенной панели просмотра ChatGPT нужно проверять в самом интерфейсе; браузерная проверка HTML не проверяет эту панель.

Зелёный футер занимает крупная надпись RAMCAD на всю ширину. Блок «О компании» расположен сразу после каталога, отдельный раздел «Другие направления» удалён. У телефона в шапке есть плавная подсветка при наведении и клавиатурном фокусе. Навигация ведёт к существующим секциям.

После сборки можно обновить переносимую версию сайта:

```bash
node scripts/export-html.mjs
node scripts/export-embedded.mjs
node scripts/export-embedded.mjs --preview
```

Полученный `index.html` открывается из корня репозитория обычным браузером. CSS, шрифты и поведение встроены; изображения и видео загружаются из соседней папки `public`. Для переноса нужны **и `index.html`, и папка `public`**. Эта версия не требует Next.js-сервера. После изменений интерфейса повторите сборку и экспорт.

## Основные файлы

- `components/landing.tsx` — секции страницы и интерактивность.
- `app/globals.css` — оформление, адаптивная сетка и анимации.
- `app/layout.tsx` — локальные шрифты, метаданные и ссылка перехода к содержимому.
- `lib/catalog.ts` — названия и изображения 36 товаров.
- `public/images/products` — исходные PNG упаковок, скопированные без перекодирования из `ramcad-assets/products`.
- `public/videos/karta_animation.mp4` — предоставленное видео маршрута.
- `public/videos/karta-scroll.mp4` и `karta-preview.mp4` — версии 1920×1080 с короткими интервалами ключевых кадров для плавной прокрутки.
- `scripts/export-html.mjs` — генерация переносимого HTML.
- `scripts/export-embedded.mjs` — упаковка полного автономного файла и лёгкого предпросмотра.
- `public/images/hero-reference.png`, `public/images/directions/reference.png` — оригинальные референсы; CSS выводит только области фотографий.
- `public/images/preview-products` — изображения в исходном разрешении с качеством WebP 95 для HTML-предпросмотра.

Старые изображения `public/images/catalog`, исторические компоненты и папка `mockup` сохранены; новая главная страница их не использует.

## Проверки

```bash
npm run lint
npx tsc --noEmit
npm run build
```

В браузере проверяйте фильтры, открытие и закрытие товара, мобильное меню, якоря, загрузку медиа и режим уменьшения движения. Отдельного автоматического test-скрипта в package.json нет.

## Источники материалов

Композиция и поведение навигации/контактов взяты из `ramcad-assets/mockups` и `ramcad-assets/references`. Названия продукции, сведения о предприятии, контакты и новости перенесены из существующих материалов HTTPCHR. Прямой запрос к icechr.ru в облачной среде возвращал HTTP 403; анализ текущей live-версии сайта не подтверждён. Новости явно помечены как архив 2024 года и ведут к исходным статьям.

Перед публичным запуском владелец должен проверить актуальность реквизитов, часов работы и сведений о производстве. Видео содержит исходное обозначение «Айсберг»; оно сохранено без изменений.
