# RAMCAD — многостраничный сайт

Сайт хладокомбината на Next.js 16, React 19 и TypeScript. Визуальное направление основано на макетах и аннотациях из соседнего репозитория `ramcad-assets`: крупная продукция MARZO, холодная палитра, верхняя навигация и видео-карта на фоне контактов. Первый экран и блок направлений повторяют предоставленные макеты: светлый первый экран и тёмный блок с двумя фотографическими карточками.

## Разработка

Проверено с Node.js 24.19.0 и npm 11.9.0.

```bash
npm ci
npm run dev
```

Производственная сборка и запуск:

```bash
npm run build
npm run start
```

Шрифты Manrope (основной текст) и Playfair Display (акцентные заголовки) хранятся локально в `public/fonts` вместе с лицензиями SIL OFL. Для сборки и просмотра не требуется Google Fonts. Дополнительные переменные окружения, ключи и база данных не нужны.

## Что работает

Четыре самостоятельные страницы с общей шапкой и футером:

- `/` — главная: первый экран с параллаксом, направления продукции, каталог, «О компании», архив новостей и контакты с анимированной картой.
- `/catalog` — каталог MARZO с фильтрами и карточками товаров.
- `/about` — история компании, производство и преимущества.
- `/contacts` — контакты на фоне сразу полностью видимой карты маршрута.

Пункты меню и кнопки ведут на соответствующие страницы. Активная страница отмечена в меню и через `aria-current="page"`. Прямое открытие и обновление каждого адреса работают. Старый адрес `/news` перенаправляет к архиву новостей на главной (`/#news`).

Справа от заголовка каталога расположена декоративная композиция из трёх последних товаров каталога MARZO; на узком телефоне она скрыта, чтобы сохранить место для заголовка и фильтров. Каталог содержит 36 товаров, шесть фильтров, разворачивание полной коллекции и подробные карточки. Диалог поддерживает клавиатуру, Escape и возврат фокуса. Кнопки сотрудничества открывают страницу контактов, телефон — звонок, почта — почтовую программу. Форма с имитацией успешной отправки на новой странице не используется; существующий `/api/contact` остаётся заглушкой и не отправляет сообщения.

На первом экране фотография и текст плавно смещаются с разной скоростью при прокрутке; смещение ограничено безопасным кадрированием на компьютере и телефоне. При прокрутке появляются блоки и заполняется индикатор чтения; активный пункт меню соответствует открытой странице. Карточки направлений слегка увеличивают фотографию при наведении. В блоке контактов на главной маршрут показан фоном из предоставленного видео. На отдельной странице контактов используется готовый кадр этой карты. Отдельного вводного блока перед картой нет. Адрес, телефон, почта и часы работы размещены в компактной полупрозрачной карточке поверх карты: на компьютере её ширина ограничена 360 px, высота определяется содержимым, а сама карточка расположена слева по центру секции. Между заголовком, контактами и расписанием равномерные отступы без растянутых пустот. На телефоне карточка расположена внизу, верхняя часть карты видна. Карта занимает всю ширину секции без горизонтального сдвига; внешней карты и переключателей нет. На главной кадр анимации напрямую связан с прокруткой: карта плавно прорисовывается до конца ближе к завершению блока. На отдельной странице «Контакты» сразу показан готовый маршрут из `public/images/map-preview.webp`: ожидать прорисовки и прокручивать страницу не нужно. Высота карты на этой странице учитывает высоту экрана. Завершение ограничено доступной прокруткой страницы, чтобы финальный кадр был доступен и на телефоне. Прокрутка вверх обращает анимацию; кадры плавно догоняют позицию прокрутки со сглаживанием 220 мс. Видео подготовлено с ключевыми кадрами через 200 мс для быстрой перемотки. Автоматического воспроизведения нет. При `prefers-reduced-motion` параллакс, плавная прокрутка и анимации отключены, видео приостановлено.

## HTML-версия

HTML-экспорт также состоит из четырёх страниц. Переходы внутри каждого семейства открывают файлы того же семейства:

| Версия | Главная | Каталог | О компании | Контакты |
| --- | --- | --- | --- | --- |
| С локальными медиа | `index.html` | `catalog.html` | `about.html` | `contacts.html` |
| Всё встроено | `ramcad.html` | `ramcad-catalog.html` | `ramcad-about.html` | `ramcad-contacts.html` |
| Предпросмотр | `preview.html` | `preview-catalog.html` | `preview-about.html` | `preview-contacts.html` |

Для обычного экспорта нужны все четыре HTML и папка `public` рядом. В автономной версии изображения, видео, CSS и шрифты встроены в каждую страницу; для переходов сохраните четыре файла одного семейства в одной папке.

В предпросмотре изображения сохраняют исходные размеры и экспортируются в WebP с качеством 95. Видео маршрута встроено в разрешении 1920×1080. Полная версия использует исходные PNG. Подключения к картографическим сервисам нет. Браузерная проверка HTML не проверяет встроенную панель просмотра ChatGPT.

Зелёный футер содержит крупную надпись RAMCAD, меню четырёх страниц и ссылку к началу текущей страницы. Блок «О компании» доступен и на главной, и на своей странице: вместо статистики и полосы слоганов — тёмно-зелёная плашка с четырьмя преимуществами и контурными иконками. На компьютере четыре колонки, на планшете две, на телефоне одна. Переход с рожком и раздел «Другие направления» удалены. Разделительные линии между секциями удалены. У телефона в шапке есть плавная подсветка при наведении и клавиатурном фокусе.

После сборки можно обновить переносимую версию сайта:

```bash
node scripts/export-html.mjs
node scripts/export-embedded.mjs
node scripts/export-embedded.mjs --preview
```

Полученные HTML открываются обычным браузером и не требуют Next.js-сервера. После изменений интерфейса повторите сборку и все три команды экспорта.

## Основные файлы

- `components/landing.tsx` — общий каркас, содержимое четырёх страниц и интерактивность.
- `app/page.tsx`, `app/catalog/page.tsx`, `app/about/page.tsx`, `app/contacts/page.tsx` — отдельные маршруты и метаданные.
- `app/globals.css` — оформление, адаптивная сетка и анимации.
- `app/layout.tsx` — локальные шрифты, метаданные и ссылка перехода к содержимому.
- `lib/catalog.ts` — названия и изображения 36 товаров.
- `public/images/products` — исходные PNG упаковок, скопированные без перекодирования из `ramcad-assets/products`.
- `public/videos/karta_animation.mp4` — предоставленное видео маршрута.
- `public/videos/karta-scroll.mp4` и `karta-preview.mp4` — версии 1920×1080 с короткими интервалами ключевых кадров для плавной прокрутки.
- `scripts/export-html.mjs` — генерация четырёх переносимых HTML-страниц.
- `scripts/export-embedded.mjs` — упаковка двух семейств автономных HTML-страниц.
- `public/images/hero-reference.png`, `public/images/directions/reference.png` — оригинальные референсы; CSS выводит только области фотографий.
- `public/images/preview-products` — изображения в исходном разрешении с качеством WebP 95 для HTML-предпросмотра.

Старые изображения `public/images/catalog`, исторические компоненты и папка `mockup` сохранены; новая главная страница их не использует.

## Проверки

```bash
npm run lint
npx tsc --noEmit
npm run build
```

В браузере проверяйте фильтры, открытие и закрытие товара, мобильное меню, переходы между страницами, прямое открытие адресов, загрузку медиа и режим уменьшения движения. Отдельного автоматического test-скрипта в package.json нет.

## Источники материалов

Композиция и поведение навигации/контактов взяты из `ramcad-assets/mockups` и `ramcad-assets/references`. Названия продукции, сведения о предприятии, контакты и новости перенесены из существующих материалов HTTPCHR. Прямой запрос к icechr.ru в облачной среде возвращал HTTP 403; анализ текущей live-версии сайта не подтверждён. Новости явно помечены как архив 2024 года и ведут к исходным статьям.

Перед публичным запуском владелец должен проверить актуальность реквизитов, часов работы и сведений о производстве. Видео содержит исходное обозначение «Айсберг»; оно сохранено без изменений.
