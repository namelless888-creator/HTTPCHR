# RAMCAD — многостраничный сайт

Сайт хладокомбината на Next.js 16, React 19 и TypeScript. Визуальное направление основано на макетах и аннотациях из соседнего репозитория `ramcad-assets`: крупная продукция MARZO, холодная палитра, верхняя навигация и видео-карта на фоне контактов. Первый экран и блок направлений повторяют предоставленные макеты: светлый первый экран и тёмный блок с двумя фотографическими карточками.

## Разработка

Проверено с Node.js 24.19.0 и npm 11.9.0.

```bash
npm ci
npm run dev
```

Производственная сборка и запуск:

```bash
npm run build
npm run start
```

Шрифты Manrope (основной текст) и Playfair Display (акцентные заголовки) хранятся локально в `public/fonts` вместе с лицензиями SIL OFL. Для сборки и просмотра не требуется Google Fonts. Дополнительные переменные окружения, ключи и база данных не нужны.

## Что работает

Четыре самостоятельные страницы с общей шапкой и футером:

- `/` — главная: первый экран с видео и параллаксом текста, направления продукции, каталог, «О компании», архив новостей и контакты с анимированной картой.
- `/catalog` — каталог MARZO с фильтрами и карточками товаров.
- `/about` — история компании, производство и преимущества.
- `/contacts` — контакты на фоне карты, которая прорисовывается автоматически при открытии страницы.

Пункты меню и кнопки ведут на соответствующие страницы. Активная страница отмечена в меню и через `aria-current="page"`. Прямое открытие и обновление каждого адреса работают. Старый адрес `/news` перенаправляет к архиву новостей на главной (`/#news`).

Справа от заголовка каталога расположена декоративная композиция из трёх последних товаров каталога MARZO; на узком телефоне она скрыта, чтобы сохранить место для заголовка и фильтров. Каталог содержит 36 товаров, шесть фильтров и разворачивание полной коллекции. Каждый товар открывается на собственной странице `/product/01`–`/product/36`. Карточки на главной и в каталоге — обычные доступные ссылки; всплывающих окон товаров нет. Кнопки сотрудничества открывают страницу контактов, телефон — звонок, почта — почтовую программу. Форма с имитацией успешной отправки на новой странице не используется; существующий `/api/contact` остаётся заглушкой и не отправляет сообщения.

На первом экране справа анимация трёх упаковок MARZO автоматически проигрывается один раз и сохраняет конечный кадр. Кнопка позволяет поставить видео на паузу, продолжить или повторить; при уходе сцены за пределы экрана и переключении вкладки воспроизведение приостанавливается. При уменьшении движения показывается неподвижный постер. Слева сохраняются заголовок и студийный фон; текст слегка смещается при прокрутке. При прокрутке появляются блоки и заполняется индикатор чтения; активный пункт меню соответствует открытой странице. Карточки направлений слегка увеличивают фотографию при наведении. В блоке контактов на главной маршрут показан фоном из предоставленного видео. На отдельной странице контактов короткая версия видео автоматически проигрывается один раз после загрузки: первые 3,1 секунды удалены, оставшаяся часть ускорена вдвое. Прорисовка занимает около 4,28 секунды. Файл `public/videos/karta-intro.mp4` сохранён в 1920×1050 с частотой 60 кадров/с. Отдельного вводного блока перед картой нет. Адрес, телефон, почта и часы работы размещены в компактной полупрозрачной карточке поверх карты: на компьютере её ширина ограничена 360 px, высота определяется содержимым, а сама карточка расположена слева по центру секции. Между заголовком, контактами и расписанием равномерные отступы без растянутых пустот. На телефоне карточка расположена внизу, верхняя часть карты видна. Карта занимает всю ширину секции без горизонтального сдвига; внешней карты и переключателей нет. На главной кадр анимации напрямую связан с прокруткой: карта плавно прорисовывается до конца ближе к завершению блока. На отдельной странице «Контакты» карта начинает прорисовываться при открытии без прокрутки. Анимация проигрывается один раз, после чего остаётся финальный кадр; прокрутка не управляет её временем. Начальный кадр `public/images/map-start.webp` используется как poster, чтобы готовая карта не мелькала перед прорисовкой. При уменьшении движения и при отказе браузера от автовоспроизведения показывается финальный кадр. Общее поведение React и HTML-версии хранится в `lib/map-intro.mjs` и `lib/map-scroll.mjs`. Высота карты на этой странице учитывает высоту экрана. Завершение ограничено доступной прокруткой страницы, чтобы финальный кадр был доступен и на телефоне. Прокрутка вверх обращает анимацию; кадры плавно догоняют позицию прокрутки со сглаживанием 300 мс и ограничением резких скачков времени. Версия для прокрутки сохранена при 60 кадрах/с с ключевыми кадрами через каждые 6 кадров (100 мс) для быстрой перемотки. В блоке карты на главной автоматического воспроизведения нет; на странице контактов видео запускается автоматически без звука. При `prefers-reduced-motion` параллакс, плавная прокрутка и анимации отключены, видео приостановлено.

Видео первого экрана `public/videos/home-hero.mp4` замедлено до 5,5 с (330 кадров) и подготовлено с MCI-интерполяцией до 60 кадров/с, CRF 14. Неизменённый оригинал сохранён в `home-hero-source.mp4`: 1280×736, 24 кадра/с, 3,041667 с. Обработка создаёт промежуточные кадры и сохраняет исходное пространственное разрешение 1280×736. Постер сохранён в lossless WebP. HTML-экспорт использует тот же обработанный клип без уменьшения разрешения. Поведение приложения и HTML общее — `lib/home-hero.mjs`.

На отдельной странице каталога видео `public/videos/catalog-intro.mp4` связано с прокруткой и занимает весь экран внутри закреплённой секции высотой 350svh. Прогресс сглаживается за 220 мс с ограничением резких скачков; подписи и стрелки появляются постепенно после завершения видео. Ролик подготовлен из неизменённого `catalog-intro-source.mp4`: MCI-интерполяция, 60 кадров/с, 183 кадра (3,05 с), GOP 3, CRF 14, исходное разрешение 1280×736.

Карта подготовлена из выбранного бело-синего ролика 848×464: Lanczos-масштабирование до 1920×1050 и умеренная резкость сохраняют его оформление. Масштабирование не создаёт новых деталей исходного изображения. `scripts/prepare-map.mjs` удаляет первые 3,1 с и сохраняет 257/30 с полезной анимации перед ускорением вводной версии.

## Страницы товаров

Для всех 36 товаров собраны самостоятельные страницы с уникальными заголовками и описаниями. Общая шапка и футер сохраняются, пункт «Каталог» подсвечен. Слева — лавандовая сцена с оригинальной упаковкой: она плавно движется по вертикали и слегка покачивается, а мягкая тень меняет размер синхронно с движением. Справа — название, описание, формат, вкус, бренд, оптовая кнопка и контакты отдела продаж. Ниже — товары той же категории и переход к сотрудничеству.

Упаковка сохраняет оригинальные цвета и фон изображения. На телефоне блоки становятся в одну колонку. При `prefers-reduced-motion: reduce` парение, изменение тени и анимации наведения отключены. Масса показана только для подтверждённой позиции №02 (100 г); составы, БЖУ и калорийность без исходных данных не добавлены. Для №28 использована соответствующая названию упаковка клубничного «Мохито» из `ramcad-assets/products/variant-39.png`.

Данные описаний и свойств находятся в `lib/products.ts`, общий шаблон — `components/product-details.tsx`, стили — `app/product-details.css`. `app/product/[id]/page.tsx` заранее создаёт 36 страниц и возвращает 404 для неизвестного номера.

## HTML-версия

HTML-экспорт каждого семейства состоит из 40 страниц: четырёх основных и 36 товарных. Переходы внутри каждого семейства открывают файлы того же семейства:

| Версия | Главная | Каталог | О компании | Контакты |
| --- | --- | --- | --- | --- |
| С локальными медиа | `index.html` | `catalog.html` | `about.html` | `contacts.html` |
| Всё встроено | `ramcad.html` | `ramcad-catalog.html` | `ramcad-about.html` | `ramcad-contacts.html` |
| Предпросмотр | `preview.html` | `preview-catalog.html` | `preview-about.html` | `preview-contacts.html` |

Товарные страницы называются `product-01.html`–`product-36.html`, `ramcad-product-01.html`–`ramcad-product-36.html` и `preview-product-01.html`–`preview-product-36.html` соответственно. Все ссылки, включая рекомендации и хлебные крошки, остаются внутри своего семейства.

Для обычного экспорта нужны все 40 HTML и папка `public` рядом. В автономной версии изображения, видео, CSS и шрифты встроены в каждую страницу; для переходов сохраните все 40 файлов одного семейства в одной папке.

В предпросмотре изображения сохраняют исходные размеры и экспортируются в WebP с качеством 95. Видео маршрута встроено в разрешении 1920×1050. Полная версия использует исходные PNG. Подключения к картографическим сервисам нет. Браузерная проверка HTML не проверяет встроенную панель просмотра ChatGPT.

Зелёный футер содержит крупную надпись RAMCAD, меню четырёх страниц и ссылку к началу текущей страницы. Блок «О компании» доступен и на главной, и на своей странице: вместо статистики и полосы слоганов — тёмно-зелёная плашка с четырьмя преимуществами и контурными иконками. На компьютере четыре колонки, на планшете две, на телефоне одна. Переход с рожком и раздел «Другие направления» удалены. Разделительные линии между секциями удалены. У телефона в шапке есть плавная подсветка при наведении и клавиатурном фокусе.

После сборки подготовьте видео и обновите переносимые версии сайта; для первых двух команд нужен установленный FFmpeg:

```bash
node scripts/prepare-motion.mjs
node scripts/prepare-map.mjs
node scripts/export-html.mjs
node scripts/export-embedded.mjs
node scripts/export-embedded.mjs --preview
```

Полученные HTML открываются обычным браузером и не требуют Next.js-сервера. После изменений интерфейса повторите сборку и все три команды экспорта.

## Основные файлы

- `components/landing.tsx` — общий каркас основных и товарных страниц, фильтры и интерактивность.
- `app/page.tsx`, `app/catalog/page.tsx`, `app/about/page.tsx`, `app/contacts/page.tsx` — отдельные маршруты и метаданные.
- `app/globals.css` — оформление, адаптивная сетка и анимации.
- `app/layout.tsx` — локальные шрифты, метаданные и ссылка перехода к содержимому.
- `lib/catalog.ts` — названия и изображения 36 товаров.
- `public/images/products` — исходные PNG упаковок, скопированные без перекодирования из `ramcad-assets/products`.
- `public/videos/home-hero.mp4`, `public/images/home-hero-poster.webp` — анимация первого экрана (1280×736, 60 кадров/с, 5,5 с) и неподвижный постер.
- `public/videos/home-hero-source.mp4`, `catalog-intro-source.mp4` — неизменённые исходные ролики 1280×736, 24 кадра/с.
- `public/videos/catalog-intro.mp4` — видео каталога с MCI-интерполяцией: 1280×736, 60 кадров/с, 3,05 с, GOP 3, CRF 14.
- `scripts/prepare-motion.mjs` — повторяемая подготовка видео главной и каталога из исходников; требует FFmpeg.
- `public/videos/karta_animation.mp4` — предоставленное видео маршрута 848×464 с белым фоном и синими линиями.
- `public/videos/karta-scroll.mp4` — версия 1920×1050 длительностью 257/30 с (около 8,566667 с), 60 кадров/с, GOP 6, CRF 15. `karta-preview.mp4` — её точная копия без снижения качества.
- `public/videos/karta-intro.mp4` — ускоренная вдвое версия: 4,283333 с, 60 кадров/с, CRF 15.
- `scripts/prepare-map.mjs` — повторяемая подготовка видео и постеров; требует FFmpeg.
- `public/images/map-start.webp` и `map-preview.webp` — постеры 1920×1050 в lossless WebP.
- `scripts/export-html.mjs` — генерация 40 переносимых HTML-страниц.
- `scripts/export-embedded.mjs` — упаковка двух семейств автономных HTML-страниц.
- `public/images/hero-reference.png` — сохранённый референс первого экрана; `public/images/directions/reference.png` — референс фотографических карточек направлений.
- `public/images/preview-products` — изображения в исходном разрешении с качеством WebP 95 для HTML-предпросмотра.

Старые изображения `public/images/catalog`, исторические компоненты и папка `mockup` сохранены; новая главная страница их не использует.

## Проверки

```bash
npm run lint
npx tsc --noEmit
npm run build
```

В браузере проверяйте фильтры, открытие всех товаров и переходы по рекомендациям, мобильное меню, переходы между страницами, прямое открытие адресов, загрузку медиа и режим уменьшения движения. Отдельного автоматического test-скрипта в package.json нет.

## Источники материалов

Композиция и поведение навигации/контактов взяты из `ramcad-assets/mockups` и `ramcad-assets/references`. Названия продукции, сведения о предприятии, контакты и новости перенесены из существующих материалов HTTPCHR. Прямой запрос к icechr.ru в облачной среде возвращал HTTP 403; анализ текущей live-версии сайта не подтверждён. Новости явно помечены как архив 2024 года и ведут к исходным статьям.

Перед публичным запуском владелец должен проверить актуальность реквизитов, часов работы и сведений о производстве. Видео содержит исходное обозначение «Айсберг»; оно сохранено без изменений.
